# HA 컴포넌트 UI 검수표

**기준:** 디자인 가이드 1.0.0 / Wallet v1.11.0 — HealthLink Studio

26개 Chromium 런타임 테스트와 화면 검수를 수행했다. 아래 통과는 로컬 가상 HA API 환경에 한정된다. 실기기·보조기술·실제 HA 조건이 포함된 항목은 미검증으로 남긴다. 실행 명령: `python tests/frontend/studio_browser_checks.py`. 알려진 한계는 UI_DESIGN.md에 기록한다.

상태는 `통과 / 실패 / 미검증 / 해당 없음(근거)`로 기록한다. 증거는 명령·로그·화면·파일 위치를 사용한다.
